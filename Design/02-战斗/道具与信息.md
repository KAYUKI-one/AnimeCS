# 道具与信息

[返回策划总览](../README.md) · [枪械与交火](枪械与交火.md) · [Bot 如何听与看](../04-Bot/拟人对手与单场学习.md)

> **模块定位与设计目的**：本模块规定单道具槽的三种投掷物规则，以及声音、视野、队伍报点如何在双方之间公平传播。
> * **为什么每人只有一个通用道具槽**：把道具管理压缩到极致——开局只需在「封视野的烟」「破点用的闪」「骗脚步的回声片」里三选一。你拿了假脚步，就得指望队友带烟过点。
> * **为什么把声音与报点规则写成铁律**：玩家和 Bot 必须处于同一套视听规则下，不能出现“烟雾挡玩家却挡不住 Bot”或“声音隔墙不衰减”的情况。

## 一、道具通用操作与三种投掷物

* **通用规则**：
  * 每人只有 **1 个通用道具槽**，每局最多携带 **1 件**，攻守双方均可购买。
  * 按道具键拿出，按主攻击键投出；**出手前切回枪械可随时取消，且保留道具不消耗**。
  * 一旦出手立即消耗道具，投出后经过 **0.45 秒** 收手动画恢复持枪。
  * 三种道具使用统一的短抛物线，首次碰撞有效场地表面后停留；若碰入不可达区域，则落回最近的有效地面。全员共享相同的抛物线与物理规则。

| 道具名称 | 价格 | 首测作用与时间轴 | 对手能读到的反制信号与队伍代价 |
| :--- | ---: | :--- | :--- |
| **烟幕** | 300 | 落地后先出现扩张提示，**0.5 秒**时闭合为 **半径 3 米** 的球/柱形烟体，持续遮挡视线 **9 秒**；随后烟体打开恢复视线，再用 **0.5 秒** 淡出边缘余烟。 | 视线穿过烟幕时，角色身影、附着标记与 Bot 目击**同时被彻底遮断**，但子弹与声音仍可正常穿过。代价是队友也可能因此失去观察窗口。 |
| **闪光** | 250 | 落地 **0.6 秒** 后引爆闪光。仅对 **10 米内**、存在直视路径且爆闪点处于视野内的角色生效：正对闪点致盲 **1.4 秒**，视野边缘致盲 **0.45 秒**，中间按角度插值。 | 落地后有明确的亮点与前摇提示音，对手可及时**背身转开**，或躲到硬遮挡物、已成形的烟幕后避开。**友方与自己遵守完全相同的致盲判定。** |
| **回声片** | 200 | 落地 **0.4 秒** 后，在原地播放连续三声间隔 **0.3 秒** 的假跑步声，紧接着播放一段**极短的电子尾音**。为固定声源，无伤害，播完自动失效。 | 前三声足够逼真，能迫使听见的人转头防备；但**紧随其后的电子尾音**和“亲眼看见走廊没人”都能帮对手识破这是假声音。它不产生人影、命中反馈或自动报点。 |

### 一回合的战术取舍案例

你在「展廊」朝前投出一枚回声片，自己立刻切换静步悄悄转向中路「导播厅」。刚听见第一声假脚步的守方，很可能会立刻转头架住展廊方向。等电子尾音响起时，对手虽能察觉上当并收回判断，但你已经利用这不到两秒的窗口抢进了导播厅。当然，如果守方本身就能直接看见空无一人的展廊，这招就骗不到人——而且为了这次欺骗，你们队伍也实打实地少带了一颗烟或一颗闪。

## 二、声音与情报如何传播

### 1. 首测可闻半径与隔墙衰减

| 声音事件 | 基础可闻半径 | 听者能读出的情报 |
| :--- | ---: | :--- |
| **跑步 / 静步 / 蹲行** | **14 米 / 4 米 / 2 米** | 声音的大致方向与远近；回声片的前三声完全复用跑步声素材与传播范围。 |
| **枪声（常规 / 消音武器）** | **38 米 / 18 米** | 具体的枪械种类与大致方向；自带消音器的「白隼-12S」与「守望-41S」可闻半径大幅缩小至 18 米（枪械涂装不改变原枪声）。 |
| **道具生效 / 回声片尾音** | **12 米 / 7 米** | 可明确辨识烟/闪/回声片；由于尾音范围（7 米）小于假脚步（14 米），站在听觉边缘的对手可能只听到脚步而漏掉尾音。 |
| **目标包开始安装 / 拆除** | **10 米** | 清晰的交互声与方位；**中途松手打断无全场提示**，听者无法通过声音偷听读条进度。 |

* **隔墙衰减规则**：声音每穿透 **一处封闭隔墙**，可闻半径减半；穿透多层封闭隔墙则继续减半。**连通的门洞（无实体遮挡）不衰减，烟幕也不阻挡声音。**
* **信息精度边界**：声音只向听者（玩家与 Bot）传递「大致区域与方位」（例如来自左侧展廊），绝不生成精确坐标或透视图标。双方阵营与全部难度共用同一套声音资源与衰减条件。

### 2. 团队标记、报点与公共信息

* **玩家标记**：玩家可对准可见场景发出「看这里 / 集合」标记。标记固定留在当时的地面位置，**3 秒后自动消退**，不会跟随移动目标，也没有任何探测透视功能。友方 Bot 会带延迟地接收标记，并结合自身当前任务决定是否响应。
* **Bot 报点**：Bot 亲眼发现敌人时会给出类似「展廊见到一人」的简短报点，同时向队友传达短时地名提示。**一旦敌人脱离视野，系统不再为队友持续刷新位置。**
* **全场公共信息**：目标包安装完成、所在包点位置以及回合胜负结果属于全场公告，所有 10 个席位同时获知。

## 三、首测道具与信息验证要点

1. **隔烟盲区测试**：让玩家与 Bot 隔着已成形的烟幕互看，双方必须同时丢失彼此轮廓，且不得产生新的自动报点。
2. **公平背闪测试**：让玩家与 Bot 同时背对落地闪光，双方均应完整保留视野、不受致盲影响。
3. **回声片欺骗与辨伪测试**：让 Bot 处于“只能听见前三声假脚步、听不见 7 米内电子尾音且看不见走廊”的位置时，它必须把声音当作真敌人脚步戒备；只有当它听见电子尾音或亲眼看到空走廊时，才允许触发“识破假声”的判断。
