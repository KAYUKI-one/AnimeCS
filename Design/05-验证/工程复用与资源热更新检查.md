# 工程复用与资源热更新检查

## 表现与游戏逻辑

项目已经按 `Core`、`Presentation`、`Infrastructure` 分目录。席位通过 `ISeatDriver` 提交操作，`LocalMatch` 推进规则并通过 `IMatchWorld` 查询移动和命中。实战 HUD、音效、角色骨骼属于表现层。这个分界已用于客户端和服务端，专用服务构建会另外生成碰撞与规则目录。[席位契约](../../Assets/Scripts/Core/Match/SeatContracts.cs) · [战斗服务构建](../../Assets/Editor/BattleServerBuild.cs)

当前这些运行时目录都编入 `AnimeCS.Runtime`，编译器允许跨层引用。体量较大的 `LocalGame` 同时负责对局进入、输入与预览、账号对接和在线会话组织。单独将某个目录复制到新项目时，需要梳理这些间接依赖。[运行时程序集](../../Assets/Scripts/AnimeCS.Runtime.asmdef) · [会话入口](../../Assets/Scripts/Presentation/Match/LocalGame.cs)

项目编辑器工具仍集中在一个 `Assets/Editor` 目录。构建、资源导入、地图烘焙与角色姿态工具有各自入口，后续按职责分目录会更容易独立维护和打包。

## UI 编辑器复用

Unity UI Builder 可编辑 UXML 布局和 USS 样式。大厅主题由 `MatchPresentation` 引用，可以在同版本的其他 3D Unity 项目中复用版式、主题与基础控件。新项目需要自己的界面绑定，当前 `LobbyScreen` 依赖具名控件、AnimeCS 账号、装备目录及角色预览场景。Unity 编辑器中的「资源管理器」也直接依赖本项目的资源类型和目录操作。整体 UI 目前适合按模板移植。[大厅布局](../../Assets/Content/UI/Lobby.uxml) · [主题配置](../../Assets/Scripts/Presentation/Match/MatchPresentation.cs) · [资源管理器](../../Assets/Editor/ContentManagerWindow.cs)

## 短 TTK 枪战复用

伤害和距离衰减集中在 `WeaponDefinition`。射击偏移由 `ShotPattern` 计算，射线、地图和历史命中通过世界接口接入。这些边界适合移植到新的 Unity 项目，角色模型、枪皮和 UI 都可按新项目选择。[枪械定义](../../Assets/Scripts/Core/Content/WeaponDefinition.cs) · [射击偏移](../../Assets/Scripts/Core/Match/ShotPattern.cs)

整套枪战还依赖本作回合裁判。开火、命中、历史回溯、经济、席位阶段与安装物处理共处 `LocalMatch.Actions`，`SeatInventory` 同时持有护甲、钱包、投掷物和角色配置。枪械定义也同时引用 Unity 的持枪模型。迁移到不同模式时，需要为弹药与射击状态、伤害结算、世界查询定义明确的入口，再由新游戏提供模式规则和美术适配。[回合行动](../../Assets/Scripts/Core/Match/LocalMatch.Actions.cs) · [席位装备](../../Assets/Scripts/Core/Match/SeatInventory.cs)

## 资源替换与热更新

| 内容 | 编辑器内替换或新增 | 发布后资源热更新 |
| --- | --- | --- |
| 角色、服装、武器、枪皮、地图 | 资源管理器支持导入、替换引用、校验目录。保留原物品 ID 可延续存档关联，新内容需登记目录。带骨骼的衣服和枪械仍需检查动作、接触点与材质。 | 运行时目录引用构建内的 Unity 资源。下载文件目前无法覆盖这些引用或登记新的条目。 |
| 大厅、HUD、枪声、脚步与持物音效 | 可在预设上换 UXML、USS、AudioClip 与持物动作库等引用。 | 预设直接引用构建资源。当前缺少从更新目录加载、切换或回退这些引用的运行时入口。 |
| 背景音乐 | 当前音频预设提供战斗与交互音效。源码和预设中未找到单独的背景音乐播放或曲库入口。 | 增加背景音乐需要同时提供播放和资源绑定入口。 |
| 下载、校验与缓存 | HotUpdate 服务提供清单和资源下载，客户端校验指纹并切换缓存指针。 | 登录后会检查清单。全仓搜索表明 `AccountClient.UpdateDirectory` 目前只有声明，未发现角色、地图、音效或 UI 消费该路径。下载结果目前停留在缓存层。 |

资源热更新下一轮可以先验收一个完整闭环。例如客户端重启后使用同一稳定 ID 的新枪皮；坏包应回退到上一个完整版本。新增物品还需要客户端目录、账号库存与商店的 ID 对齐，影响碰撞或战斗数值的资源还需要与战斗服务对齐。本轮检查未调整这条链路。
