# 本地对局边界与试玩验收

[返回策划总览](../README.md) · [系统清单](../00-全局设计/系统清单.md)

> **模块定位与设计目的**：本模块规定本地单机版的系统架构边界（为未来扩展联机留出接缝），以及首测可玩版本必须跑通的全部验收标准与试玩调优口径。
> * **为什么在单机版就切分三层边界**：哪怕首测只在一台电脑上运行、完全不接入网络服务，只要把“谁提交操作”“谁做唯一裁定”“谁能看到什么信息”在逻辑上彻底拆开，将来把部分本地 Bot 席位换成远端玩家时，就不需要重写比赛规则、判定或防作弊逻辑。

---

## 一、为未来联机预留的三道系统边界

本期所有逻辑（时钟、10 个席位、胜负裁定与本地存档）全部在一台机器上完成，不依赖在线大厅、传输协议、远程服务器或联网登录；但代码与系统接口按以下三道边界隔离：

| 系统边界 | 本地单机版如何运行 | 将来扩展联机时接在哪里 |
| :--- | :--- | :--- |
| **1. 席位提交操作意图** | 人类玩家的键鼠输入与 9 个 Bot 的决策，统一以「某席位、在某时刻、请求移动 / 开火 / 购买 / 交互」的形式提交。**包括 Bot 在内，任何席位只能表达意图，不能自己改血量或金钱。** | 将远端网络玩家作为另一种「操作意图来源」接入同一席位接口即可。 |
| **2. 比赛裁判唯一裁定** | 裁判系统按统一比赛时钟，结合当前状态校验余额、存活、弹量与交互条件，**唯一发出**命中结果、装备变更、装拆成功与回合结算事件；重复交互或并发结算只生效一次。 | 未来可将裁判逻辑迁往权威主机或服务器，核心比赛规则完全复用。 |
| **3. 按接收者分发可见信息** | 每个席位只能收到自己的装备与已合法获知的视听情报；同队收到有权限的队伍报点；全员收到公共比分、装包公告与阶段时钟；角色和枪械只下发稳定外观 ID。 | 未来只需将这套“分权限席位视图”分别下发给不同客户端，即可天然隔绝透视外挂。 |

**运转示例**：某名 Bot 在场内听到 14 米内的脚步声后，只能向比赛系统提交“将视角转向该方位”的意图；比赛裁判接受其朝向变化后，在下一次视觉射线检测中确认目标真的进入该 Bot 100° 视野且未被烟幕或墙体遮挡，才允许它进入 ≥240ms 的识别与开火流程。**完整场景坐标与隐藏真值只供裁判计算和赛后离线调试读取，观战画面同样只读取被观战席位的合法可见信息。**

## 二、首轮试玩准备与记录口径

* **最小全流程内容闭环**：只需准备 **1 张灰盒图**（「云上转播站」，含 A/B 点与 4 个命名区域）、**1 名共用基础角色 + 2 套示范服装 + 12 把原厂枪 + 3 款替换枪皮**、**3 种道具 + 胸甲与头盔 + 10 个席位**，即可从局外衣柜、购买、交火、观战一直打到 13 胜结束与赛后复盘。首轮素材可先做功能性简化，但必须保证**袖口辨识度、掉落枪皮辨识度、友方头顶 ID 和肩背标识与回声片电子尾音**清晰可辨。
* **试玩自动采集口径**：
  * **对局基础信息**：每局记录难度设置、随机种子、双方攻守职责、当前比分、胜因、每人收支与保留装备、安装/拆除记录。
  * **战斗与 Bot 专项**：记录每次有效交火的「首次互见 → 开出第一枪」与「首发命中 → 目标倒地」耗时；额外记录 Bot 线索来源与过期时刻、自动难度调档记录及单场学习样本计数。
  * **公平归因原则**：在审视试玩反馈时，将“短 TTK 带来的合法一枪爆头”与“先手信息优势”分开统计——一发合法的远距离爆头秒杀不能被误判为 Bot 瞬间锁头。

## 三、核心验收用例清单

以下 12 项用例覆盖全系统的核心规则与边界情况。策划评审阶段用于纸面逻辑走查，程序实现后作为首轮试玩验收标准：

| 序号 | 验收模块 | 测试操作 / 输入条件 | 预期通过标准 |
| :---: | :--- | :--- | :--- |
| **1** | **完赛与换边** | 分别模拟走到 `13∶0`、`13∶11` 与 `12∶12` 后打完第 25 局 | 均在第 12 局后正确换边；三场分别在第 13、24、25 局结束；决胜局全员 4,000 预算；加分与奖励每局仅发一次。 |
| **2** | **目标包与同刻裁定** | 依次测试：安装读条未满时争夺超时、装包后攻方全灭、双方同刻全灭、倒计时归零同刻完成拆除 | 与 [胜负裁定表](../01-比赛/赛制与首图.md) 完全一致；装包后守方有人时继续计时；争夺到期优先，拆除与引爆同一模拟步时拆除优先。 |
| **3** | **友方接管目标** | 玩家持包阵亡后只观战；另开一局让玩家全程挂机不发任何指挥指令 | 友方 Bot 能主动捡包并尝试安装，守方能回防拆除；任一方不依赖人类玩家确认即可推进并正常结束回合。 |
| **4** | **经济账单校验** | 跑通 [三个典型购买决定](../02-战斗/经济与购买.md)，再额外覆盖满钱包 10,000 截断与替换继承物后撤销 | 余额与示例完全一致，超出 10,000 部分在账单标明溢出；撤销替换时原继承物和涂装完整恢复，绝无重复退款漏洞。 |
| **5** | **CS2 枪感与急停基线** | 测试「炽焰-47 / 折线-44 / 长镜-96」对有甲目标的头/胸/腹/腿伤害；测试反向急停踩进 34% 阈值后的固定弹道与跑动随机扩散 | 伤害与 TTK 与 [枪械与交火表](../02-战斗/枪械与交火.md) 一致（炽焰-47 一枪有甲头、折线-44 头留残血、长镜-96 胸腹秒杀腿剩 15）；停稳连发走固定轨迹，跑动触发随机扩散。 |
| **6** | **遮挡与防锁头** | 用同一随机种子跑两次测试：目标被烟/墙遮挡后分别向左转、向右转，屏蔽其他声音与报点，随后在入口重新现身 | 产生新线索前，两次测试中 Bot 的观察动作完全一致；无隔烟修正或穿烟补枪；重新现身后首发耗时均 ≥240ms、转速均 ≤240°/s。 |
| **7** | **回声片与闪光** | 隔墙投掷回声片，分别置于“听得见尾音（≤7m）”和“仅听见假脚步（7–14m）”位置；让背对和正对闪光的角色同时经历爆闪 | 前三声走普通脚步通道；只有实际听到尾音或亲眼看见空走廊才能辨伪；背对闪光保留完整视野，致盲期间立即撤销现有视觉锁定目标。 |
| **8** | **自动难度调节** | 基准设为「标准」，构造连续两个 3 局窗口各 4 次有效交火且玩家均胜 3 次；再测 6 局连败、样本不足、上下波动与关闭调节 | 双窗高胜率例在第 7 局升至「挑战」协作，6 战连败例降至「休闲」，其余保持「标准」；全过程不改动感知、伤害、金钱与当局行为。 |
| **9** | **挑战单场学习** | 复现 [五局演练例子](../04-Bot/拟人对手与单场学习.md)，对照组第 1–4 局只丢回声片不现身，随后测试半场换边与重开新比赛 | 实验组第 5 局出现有据可查的展廊观察倾向，第 6 局可正常撤销；对照组无任何目击计票；换边后读写独立职责记录，新开场全部清零。 |
| **10** | **外观全流程归属** | 首次进衣柜混搭，入局掉枪让敌人捡起，经历换边并重启游戏；另测试损坏单个枪皮 ID | 第一人称、第三人称、地面与观战完全符合 [涂装生命周期规则](../03-外观/角色服装与枪皮.md)；战斗数值完全不变；异常槽位单槽回退原厂，不阻断开赛。 |
| **11** | **友方头顶 ID** | 从正侧面和背面观察同款角色，测试蹲伏、墙后、阵亡、观战及换边 | 活着且可见的友方有 ID，敌方没有。遮挡后收起，重新现身时跟随头部。 |
| **12** | **纯本地离线闭环** | 禁用所有外部网络，从新建本地档案进衣柜打完一场，并在争夺阶段和读条阶段分别执行暂停再恢复 | 10 个席位顺利完赛并正常保存档案；暂停期间比赛时钟、Bot 行动与装拆读条同步冻结，恢复后无缝续接。 |

## 四、首轮试玩调优决策表

试玩完成后，按以下五个核心问题判读数据并决定先改哪里，避免凭感觉盲调数值：

| 试玩观察到的核心问题 | 数据排查与调优决策方法 |
| :--- | :--- |
| **1. 感觉死得太快，是枪械 TTK 太短还是 Bot 获取信息太快？** | 分枪型、有无甲抽取至少 30 次有效交火，分别看「首次互见→首发」与「首发命中→击倒」耗时。若首发过快先排查线索来源与识别延迟；若纸面 TTK 合理但实战拖长，再微调移动散布与收回速度。 |
| **2. 整场下来会不会频繁出现“输方买不起枪无事可做”？** | 重点核对首败后的两局购买流向：检查 1,900 收入是否能稳定撑起冲锋枪或进阶手枪翻盘局，存一局后的 4,300 能否稳定形成「炽焰-47 / 折线-44 + 护甲 + 烟幕」配套，并访谈试玩者当时选择存钱或花钱的真实理由。 |
| **3. 明明换了服装或枪皮，为什么看不出来或分不清敌我？** | 先执行 [外观盲测验收](../03-外观/角色服装与枪皮.md)，再让玩家口述自己第一人称袖口与捡到枪的主题特征。按服装款式和地图明暗点位交叉统计失读率，精准定位失读场景。 |
| **4. 挑战难度让玩家觉得“它在针对我的套路”还是“它在作弊读位置”？** | 逐条复盘触发观察调整的回合，必须能 100% 追溯到合法目击样本；同时跨多个随机种子确认同一倾向下仍保持 60%/40% 的策略多样性。**只要出现一次经证实的隐藏坐标泄露，即判定存在严重缺陷优先修复。** |
| **5. 回声片到底值不值得占用唯一一个道具槽？** | 要求每名试玩者在实战中至少使用烟、闪、回声片各 2 次，赛后复述投出回声片的战术意图与对手当时收到的信号。若多数人无法解释何时该带回声片，优先调优假脚步声效与尾音区分度，再考虑扩充道具池。 |
