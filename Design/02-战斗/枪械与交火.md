# 枪械与交火

[返回策划总览](../README.md) · [经济与购买](经济与购买.md) · [道具与信息](道具与信息.md)

> **模块定位与设计目的**：本模块规定本作的移动急停、弹道散布、伤害计算与首测 12 把枪械的数值参数。
> * **为什么全面对标 CS2 射击手感**：保留玩家最熟悉的「速度阈值急停」与「高风险高回报短 TTK」——步枪跑动时无法精准命中，通过反向急停瞬间踩进低速区间即可打出一发满精度子弹；攻方主力步枪「炽焰-47」具备全常见距离有甲一枪爆头的能力。
> * **为什么在此基础上简化压枪**：取消复杂难背的后期大回环弹道，**停稳状态下采用极低随机扩散的简化固定弹道**（前几发稳定垂直上抬，后续呈现易读的规律偏移），而**移动或腾空时叠加明显的随机扩散**，让“站稳控枪”和“边跑边打”的收益差距清晰直观。
> * **为什么攻守拥有部分差异枪械**：双方各自拥有定位鲜明的专属武器（如攻方高威一枪头步枪与高机动冲锋手枪，守方消音精准步枪与高射速近防冲锋枪），并在局内支持捡起对手掉落的专属枪械，增添经济与战利品博弈乐趣。

## 一、基础生命与命中判定

* **生命上限**：每名角色固定 **100 点生命值**，单局内无任何回血或倒地扶起机制。
* **射线判定**：首版全部枪械采用**瞬时射线（Hitscan）**。开火瞬间从统一游戏视点沿实际弹道射出，命中射线上第一个有效身体部位或硬质场景遮挡。
* **四区部位判定**：全身划分为 **头部**、**胸部（含手臂）**、**腹部（含骨盆）**、**腿部** 四个判定区域（与 CS2 保持一致，以区分“打胸”和“打腹”的击杀枪数，特别是狙击枪打腿不秒杀的规则）。
* **遮挡与友伤**：
  * 硬质场景遮挡物阻挡子弹射线；**烟幕只挡视线，不挡子弹**。
  * 友方角色身体会挡住子弹，但**友方伤害为零**（不会误伤队友）。
* **绝对公平的判定体**：受击判定仅由角色基础姿态（站立/蹲伏）决定，**任何服装款式、头发造型与枪械涂装均不改变碰撞体大小**。

## 二、CS2 对标伤害计算公式与护甲机制

### 1. 单发伤害公式

$$\text{单发伤害} = \lfloor \text{基础伤害} \times \text{距离衰减系数}^{\left(\frac{\text{命中距离}}{12.7\text{米}}\right)} \times \text{部位倍率} \times \text{护甲穿透系数} \rfloor$$

> 注：每一发子弹的最终伤害都会在相乘后**向下取整**。

* **部位倍率**：
  * **头部**：**4.0**
  * **胸部（含手臂）**：**1.0**
  * **腹部（含骨盆）**：**1.25**
  * **腿部**：**0.75**
* **护甲机制与穿透系数**：
  * 首测商店提供 **1 种整套护甲（600 信用点）**，同时保护头部与躯干（胸/腹），**整局有效且无耐久度消耗**，只要存活就不会碎甲。
  * 目标**无甲**，或命中**腿部**时：公式中的「护甲穿透系数」固定为 **1.0**（打腿不吃护甲减伤）。
  * 目标**有甲**且命中头/胸/腹时：直接乘以该枪械专属的 **对甲穿透系数**（不同枪械穿甲能力差异极大，例如「街头-20」只有 0.47，而「重响-50」「炽焰-47」「长镜-96」高达 0.775–0.975）。

### 4. 武器特殊操作与消音特性

* **开镜机制**：仅「轻羽-08」与「长镜-96」具备低倍/高倍两段开镜（1.5x / 2.5x，或首测先统一 2.0x 快速切入），切入开镜耗时 **0.15 秒**，开镜后移动速度大幅下降，且每次击发后会自动退镜拉栓（约 1.25 秒 / 1.46 秒后可再射）；其余 10 把枪均采用腰射准星。
* **消音特性**：「白隼-12S」与「守望-41S」自带不可拆卸消音器，不仅后坐更易控，且**枪声可闻半径从常规 38 米缩小至 18 米**（同时不产生枪口曳光轨迹，更难隔烟反定位）。
* **半自动与换弹**：半自动手枪每次按键最多击发 1 枪，连点受射速上限限制；换弹在读条完全结束时才将备弹补入弹匣，途中切枪会中断换弹；主副武器切换统一耗时 **0.35 秒**。所有替换涂装沿用原枪的操作时刻、遮屏范围与枪声。

### 核心设计体验对齐

* **手枪局博弈**：攻防初始手枪面对无甲敌人都可近距一枪头秒杀；面对 600 护甲则必须至少两枪头或大量点身体。而「裁决-57 / 疾走-9」能在极近距离一枪穿甲爆头，「重响-50」则在全常见交火距离都能一枪穿甲爆头。
* **步枪的核心差异**：「炽焰-47」哪怕在 40 米远距依然能**一枪带走满血带甲目标（104 伤）**；「守望-41S」和「折线-44」打有甲头部为 **98 / 89 伤**（必须补一枪身或第二枪头），各自用消音低后坐（41S）和更大弹匣高射速（44）来平衡对抗。
* **轻狙与重狙定位**：「轻羽-08」主打高移速、一枪爆头与两枪身，适合中前压与半起局；「长镜-96」只要命中胸腹及头部即可一枪倒地，唯有打中腿部才会留下 15 血给对手逃生。

## 五、移动、急停手感与简化弹道规则

### 1. 持枪移速与急停阈值（CS2 急停手感）

不同于固定读秒恢复，本作的移动射击惩罚**实时挂钩当前角色水平移动速度**：

| 枪械类型 | 标准满跑速 | 静步速度 | 蹲行速度 | 精准速度阈值（停稳区间） |
| :--- | :--- | :--- | :--- | :--- |
| **手枪 / 轻羽-08** | 6.0 米/秒 | 3.1 米/秒 | 2.0 米/秒 | **≤ 2.04 米/秒**（最大跑速的 34%） |
| **冲锋枪（蜂鸟-9 / 火花-10）** | 5.8 米/秒 | 3.0 米/秒 | 1.9 米/秒 | **≤ 1.97 米/秒**（最大跑速的 34%） |
| **步枪（41S / 44 / 47）** | 5.5 米/秒 | 2.8 米/秒 | 1.8 米/秒 | **≤ 1.87 米/秒**（最大跑速的 34%） |
| **重型狙击（长镜-96）** | 5.0 米/秒（开镜 2.5） | 2.6 米/秒 | 1.7 米/秒 | **≤ 1.70 米/秒**（最大跑速的 34%） |

* **急停怎么生效**：
  * **自然松手停步**：依赖地面摩擦力减速，速度需要约 **0.18–0.22 秒** 才会滑入「≤34% 精准速度阈值」。
  * **反向急停（Counter-Strafe）**：玩家松开原方向键的同时反方向轻点移动键施加反向加速度，水平速度将在 **约 0.08–0.10 秒** 内骤降至零，**瞬间踩进精准速度阈值，立刻具备首发满精度**。
  * **蹲行与静步**：蹲行移速本身低于 34% 阈值，边蹲边挪依然享有停稳精度；静步速度处于阈值之上但远低于跑动，只承受轻度随机扩散。

### 2. 停稳固定弹道（简化压枪）与移动随机扩散

| 射击状态 | 弹道与散布表现规则 |
| :--- | :--- |
| **停稳状态（≤34% 阈值）** | • **近似无扩散的固定弹道**：首发仅保留极微小的枪械固有精准半径（狙击开镜/步枪极小，仅用来区分超远距离有效射程；玩家与 Bot 共用同一套采样）。<br/>• **简化压枪曲线**：全自动武器连发时不再做复杂的左右大摆动。**前 4 发平稳垂直上抬**（极易做 2–4 发短点射控枪），**第 5–12 发呈现固定、可预期的小幅上抬与单向折返偏移**，12 发之后保持小幅规律横摆。**停稳时弹道轨迹基本固定，玩家只需按规律下拉准星即可压住一条线。**<br/>• **后坐力恢复**：松开开火键约 **0.25–0.35 秒**（手枪/冲锋枪较快，步枪/重响-50 稍慢）回到首发点。 |
| **移动与空中状态** | • **强随机扩散惩罚**：只要水平速度超过 34% 阈值，或处于起跳/腾空/落地瞬间，即刻在准星与弹道上按比例叠加**随机扩散圆**。<br/>• **跑打宽容度差异**：<br/>　- **街头-20 / 疾走-9 / 蜂鸟-9 / 火花-10**：跑动随机扩散惩罚较小，近距离可边移动边扫射压制。<br/>　- **轻羽-08**：常规跑动扩散大，但在**跳跃最高点附近（垂直速度趋近于零时）几乎消除空中扩散惩罚**，保留经典的“跳狙”玩法。<br/>　- **炽焰-47 / 守望-41S / 折线-44 / 重响-50 / 长镜-96**：跑动及空中随机扩散极大，必须急停踩稳或蹲稳后才能精准开火。 |

## 六、交火反馈与复盘数据

* **局内反馈规则**：
  * **受击表现**：仅在目标肉眼可见时，通过局部受击动作反馈命中；**隔着烟幕打中敌人或击中掩体时，绝不给攻击方提供任何命中提示音**。
  * **阵亡摘要**：阵亡后向玩家展示致死枪械、命中部位及承伤次数；**敌人实时位置与瞄准轨迹不在局内暴露**，统一留待赛后调试复盘查看。
* **试玩采样要求**：首测同步记录「首次互见 → 开出第一枪」与「第一发命中 → 目标倒地」两段耗时，用于分别校验 Bot 反应合法性与枪械实际 TTK 手感；并将“炽焰-47/重狙一枪秒杀”与“连续多发扫射对枪”分开统计。
