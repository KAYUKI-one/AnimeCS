# 大厅与对阵页制作

## 替换美术

| 位置 | 编辑入口 | 用途 |
| --- | --- | --- |
| 大厅布局和配色 | `Assets/Content/UI/Lobby.uxml`、`Lobby.uss` | 在 UI Builder 中调整导航、卡片、弹窗和响应式布局。功能按钮以 UXML 的 name 连接控制器，调整样式时保留已有名称。 |
| 大厅背景和人物脚下阴影 | `Assets/Content/UI/Competitive.asset` | 更换大厅背景材质、接触阴影材质。前景角色、武器和队友使用玩家的展示配置。 |
| 导航图标 | `Assets/Content/UI/LobbyIcons` | 用新图替换对应图标，保留原有 Unity GUID 即可沿用界面绑定。 |
| 角色卡、库存、装备缩略图 | 角色、武器、皮肤、穿戴物各自的定义资产 | 更换 Inspector 中的立绘、头像或缩略图。透明图在浅色和深色面板均可使用。 |
| 地图对阵页 | 各 `MapDefinition` 的「加载背景」「加载页地图简介」及雷达图 | 更换该地图的横幅、地图描述或平面图。进度、阵营、席位和模式来自当前对局。 |
| 对阵卡样式 | `Assets/Content/UI/BattleLoading.uss` | 控制双方颜色、卡片尺寸、文字和进度条。此主题绑定在 `Competitive.asset`。 |

对阵卡默认使用 320 × 576 的正面半身图。选中 `Assets/Content/Data/Characters` 下的某个角色，把画师交付的 Texture2D 拖到「对阵卡正面立绘」，就能单独替换这一位角色。已有立绘和比分栏头像各有独立槽位。

更换模型后可执行 **AnimeCS → 美术 → 生成角色正面对阵卡**。编辑器从当前目录的所有可用人形角色取景，在 `Assets/Content/UI/Portraits/Match` 生成图片。单独指向其他位置的美术立绘会继续使用。加入新角色时，同时在内容目录登记人物和阵营基础服装。

## 制作每日任务

在 **AnimeCS → 任务 → 每日任务编辑器** 中添加任务，输入稳定的任务 ID、标题和说明，选择登录、进入练枪场、进入爆破对局或完成爆破回合，填写目标次数、经验和星币奖励，然后保存。每天的进度和领取记录按账号与 UTC 日期存储。同一任务只可领取一次。编辑已上线的任务时保留 ID 可延续当天的进度。

编辑器写入 `Servers/Data/game-catalog.json`。将该文件随 Data 服务发布并重启即可读取变更。在本地使用已打包的服务时，也要更新其程序目录里的同名文件后重启。配置中的 `starterItems` 为初始库存，`characters` 为角色招募池，`offers` 为可购外观。物品 ID 应与 Unity 内容资产中的 ID 一致。

## 声音和动作

持物动作库按内容 ID 选择动作曲线和声音。第一人称和第三人称表现可以在武器校准窗口预览。枪、刀、各类道具和目标装置的原始声音、参数与使用方式见[持物表现与声音](../../ArtSource/Audio/持物表现与声音.md)。本地联机、服务部署和热更新发布步骤见[联机与部署](../../Servers/README.md)。
