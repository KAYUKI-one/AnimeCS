# 赛制、回合与首图

[返回策划总览](../README.md) · [游戏术语表](../00-全局设计/游戏术语表.md)

> **模块定位与设计目的**：本模块规定一场 5v5 攻守拆弹比赛的胜负法则、单局节奏与首张地图「云上转播站」的空间结构。
> * **为什么采用 13 胜 + 12 局换边 + 第 25 局等额决胜**：让双方在攻防两端拥有平等的局数机会；一旦打平至 12∶12，直接用同一笔起手预算一局定胜负，避免前序经济碾压延续到决胜局。
> * **为什么首图结构强调简单清晰**：用直观的“双边直达 + 中路变向 + 守方连桥”结构，确保玩家和 Bot 在首测阶段都能快速看懂路线、听懂声音、完成攻防转点。

---

## 一、整场比赛规则

### 1. 开局与席位

* **开局设置**：开赛前玩家可选择 Bot 基准难度（休闲 / 标准 / 挑战）、是否开启自动难度调节，以及首发阵营（先攻 / 先守 / 随机）。
* **席位分配**：玩家固定占 1 个席位，与 4 名友方 Bot 组队，对阵 5 名敌方 Bot。
* **阵亡与观战规则**：
  * 玩家阵亡后退出当局场内行动，自动切换为观战存活队友的第一人称视角，且**只能听见该队友能听见的声音**。
  * 阵亡玩家在当局剩余时间内不能发送标记或指挥队友。
  * 若己方全灭但目标包仍在倒计时（已安装阶段），画面切换为公共视角（仅展示安装点位、公共倒计时与当前比分），直到胜因揭晓。
* **离线暂停**：玩家在单机模式下随时可以暂停，暂停期间所有席位行动、回合时钟与交互读条同步冻结。

### 2. 胜负与换边机制

* **胜利目标**：先赢满 **13 局** 的一方赢得整场比赛。
* **半场换边**：前 **12 局** 结束后双方互换攻守职责。
  * **保留项**：双方当前积分。
  * **重置项**：所有席位的钱包信用点、队伍连败档与身上装备全部清空重置（哪怕比分是 12∶0，也必须换边打第 13 局并再赢 1 局才算获胜）。
* **第 25 局决胜局**：若比分战至 **12∶12**，进入第 25 局决胜：
  * 开赛前通过独立抽签决定并公示决胜局的攻守方（便于后续试玩单独统计先后手优势）。
  * 清空继承装备，双方每人统一发放 **4,000 信用点** 与本方初始手枪（恰好够攻守双方各自买齐主力步枪 + 护甲 + 任意道具）。
* **阵营造型同步**：每次分配阵营时（开赛、半场换边、决胜局），所有 10 个席位同步切换攻守造型——攻方统一戴面罩遮住口鼻，守方露出口鼻（详见 [角色、服装与枪皮](../03-外观/角色服装与枪皮.md)）。

## 二、单局四阶段流程

```mermaid
flowchart LR
    P1["购买阶段（15秒）<br/>出生区隔离选购、撤销、标点"] --> P2["争夺阶段（95秒）<br/>交火、带包推进与安装"]
    P2 -- "未安装（全灭或超时）" --> P4["结算阶段（4秒）<br/>冻结伤害与拾取，发钱算分"]
    P2 -- "完成安装（3秒读条）" --> P3["已安装阶段（35秒）<br/>公开点位与倒计时，守方拆除"]
    P3 -- "拆完或引爆" --> P4
```

| 阶段 | 首测时长 | 玩家可执行的操作与限制 |
| :--- | :--- | :--- |
| **购买阶段** | 15 秒 | 双方隔离在各自出生区；可购买/撤销装备、查看队友配置、给出集合标记。 |
| **争夺阶段** | 95 秒 | 解除隔离正式接敌；攻方拾取并推进安装目标包，守方阻止安装或消灭攻方。 |
| **已安装阶段** | 35 秒 | 安装完成瞬间，**原争夺时钟作废**，切换为 35 秒装置倒计时并向全员公开所在点位；守方可尝试拆除。 |
| **结算阶段** | 4 秒 | 立刻冻结所有伤害与拾枪；公布本局胜因、新比分、收支明细与存活保留物，随后进入下一局或赛后复盘。 |

> **对局时长目标**：首测希望一场正常比赛耗时控制在 **25–40 分钟**。在极端情况下（打满 25 局，且每局都在第 95 秒极限装包并耗尽 35 秒倒计时），纯对局时长上限约为 **62 分钟**（不含暂停）。试玩记录中会将“实际交火时长”和“阵亡后等待时长”分开统计，防止误调阶段时间。

## 三、目标包与胜负裁定

### 1. 目标包的流转与交互

* **持有与掉落**：
  * 攻方全队仅 1 个目标包，占用独立槽位，不占用枪械或道具槽。
  * 首局按出生位轮转指定携带者，之后每局按攻方席位依次循环指定。
  * 携带者可主动丢出目标包，阵亡后原地掉落；**仅攻方可以拾取**。
  * 己方全员可知当前携带者或掉包位置；守方在安装完成前，只能靠眼睛看见或耳朵听见获取目标包线索。
  * 若目标包掉落进不可达区域，自动复位至最近一次可达的地面落点。
* **安装与拆除规则**：
  * **安装**：携带者在 A 或 B 点区内按住交互键 **3 秒** 完成安装。
  * **拆除**：守方在已安装装置的交互范围内按住交互键 **5 秒** 完成拆除。所有守方共用这一 5 秒目标，**但多人同时交互时按最先开始者占用，不累加进度**。
  * **打断条件**：松开按键、走出范围、开火或死亡，都会立即清空个人当前进度；**单纯受到伤害不会打断读条**。
  * **视听信息**：开始安装和开始拆除时，均会发出一声近处可闻的提示音（范围见 [道具与信息](../02-战斗/道具与信息.md)）；拆除进度条仅操作者本人可见。

### 2. 胜负裁定表与同刻结算顺序

| 局面 | 胜负裁定 |
| :--- | :--- |
| 争夺阶段时间耗尽，安装仍未完成（含正在读条但未满 3 秒） | **守方胜** |
| 目标包安装前，仅一方全部阵亡 | **仍有存活席位的一方胜** |
| 目标包安装前，双方在同一时刻全部阵亡 | **守方胜**（目标未被安装） |
| 目标包安装后，攻方全部阵亡，但守方仍有人存活 | **比赛继续**（进入倒计时，守方仍须拆完装置） |
| 目标包安装后，守方全部阵亡（含双方同刻全灭） | **攻方胜** |
| 守方在 35 秒内完成拆除 / 35 秒倒计时归零 | 分别判 **守方胜 / 攻方胜** |

**同一时刻发生多件事的结算优先级（由高到低）**：
1. **阶段超时**：若恰好到达阶段截止时刻，最先结算超时判负/判胜。
2. **伤害与交互中断**：先结算子弹伤害、阵亡及由此引发的读条打断。
3. **存活者的交互完成**：确认未被中断的读条是否恰好完成。
4. **全灭判定**：最后检查双方是否全部阵亡。

> 首个触发的胜因立即锁定本局比分，每局胜负奖励只发放一次。装置倒计时归零时以场地特效收尾，结算冻结时刻仍存活的席位按正常存活规则保留装备带入下一局。

## 四、首图结构草案「云上转播站」

### 1. 区域与命名规范

全图围绕两个包点与四个共用通道区域构建，玩家简报、语音报点、调试复盘与 Bot 均统一使用以下地名：

* **两大目标点**：露天「**展台 A**」与室内「**录音棚 B**」，两点结构可从入口处一眼辨认。两点均各自提供至少 **2 个** 可用于安装目标包的站位。
* **四大通道区域**：
  1. **展廊**：连接攻方出生点与展台 A 的外侧主路。
  2. **后台**：连接攻方出生点与录音棚 B 的内侧主路。
  3. **导播厅**：位于地图中路下沉区域，向两侧连通展台 A 与录音棚 B。
  4. **连桥**：位于守方后场，连接展台 A 与录音棚 B 的守方快速回防通道。

> **可读性原则**：人物活动背景需保持稳定的明度对比，避免场景明暗剧烈反差吞没角色轮廓，影响敌我与服装辨识（具体材质与灯光细节留待后续美术阶段）。

### 2. 通道连接与移动耗时基准

| 灰盒连接路径 | 承担的战术选择与结构要求 |
| :--- | :--- |
| **攻方出生 → 展廊 → A** <br/> **攻方出生 → 后台 → B** | 两侧各提供一条直达两点的主要进攻路；路线上分段布置转角与遮挡，双方出生区互不可见。 |
| **攻方出生 → 导播厅 → A 或 B** | 中路变向通道；攻方跑步经过时脚步有机会被守方听见，但其最终去 A 还是去 B 仍需二次确认。 |
| **守方出生 → 连桥 → A 或 B** | 守方在两点之间回防转点的专属通道，途中设有明确的视线中断遮挡。 |

**首测跑图耗时锚点（按步枪持枪跑速 5.5 米/秒估算）**：
* 守方从出生点抵达本侧首道观察位：**6–8 秒**（确保守方先落位）。
* 攻方从出生点直达首次可能交火区：**9–12 秒**。
* 从 A 点区经连桥转点至 B 点区：**9–13 秒**。
* **遮挡公平原则**：所有视线中断结构必须同时有效遮挡玩家与 Bot；当单枚烟幕封住某一处入口时，该区域仍应保留至少一条可绕行或可推进的连通路线。

## 五、一局流程示例（玩家视角）

1. **购买阶段**：你看见两名队友已经购买了烟幕，于是决定改买一枚价格更低的「回声片」准备用来制造假脚步。
2. **争夺阶段**：开局后己方一名队友持包走「后台」进 B，你在「展廊」方向扔出回声片吸引守方注意力。随后持包队友阵亡，目标包掉落在原地，另一名队友迅速赶去捡起并在录音棚 B 完成 3 秒安装。
3. **已安装阶段**：B 点位置立即向全场公开，35 秒倒计时开始。不久后己方全部阵亡，你的视角切为公共信息画面继续盯住倒计时。守方最终在倒计时归零前完成 5 秒拆除。
4. **结算阶段**：系统判定「守方拆除胜」，给出本局双方收支与保留物账单，你据此决定下一局是全起配枪还是存钱。
