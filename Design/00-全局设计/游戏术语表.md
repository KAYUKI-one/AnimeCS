# 二、游戏术语表

[返回策划总览](../README.md) · [系统清单](系统清单.md)

> **编写目的**：统一策划与后续开发对核心概念的称呼，避免同一名词在不同文档中含义漂移或混淆。

---

## 一、范围与席位

| 术语名 | 通俗定义 | 所属模块 | 备注与易混区分 |
| :--- | :--- | :--- | :--- |
| **一场比赛（Match）** | 从开局配置开始，直到一方率先赢满 13 局（含决胜局）并结束复盘的完整对局 | 赛制与回合 | 与「一局/回合」区分；不要简称“一局”。 |
| **一局 / 回合（Round）** | 比赛中的单个攻防轮次，包含购买、争夺、可选的已安装和结算四个阶段 | 赛制与回合 | 是加分与发放经济的基本单位。 |
| **席位（Seat）** | 一场比赛中 10 个固定参赛位置之一（攻防各 5 个），人类玩家占 1 个，其余 9 个由 Bot 担任 | 本地边界 / 赛制 | 席位是提交操作意图和接收可见信息的基本实体，不因玩家阵亡而消失。 |
| **攻方 / 守方** | 比赛中的两大阵营：攻方负责携带并安装目标包，守方负责阻止安装或拆除已安装的装置 | 赛制与回合 | 半场换边及决胜局会重新分配阵营职责。 |
| **首测数值** | 文档中用于首轮可玩验证的基准参数 | 全局 | 均为可调整起点，非最终锁定平衡值。 |

## 二、赛制与回合

| 术语名 | 通俗定义 | 所属模块 | 备注与易混区分 |
| :--- | :--- | :--- | :--- |
| **目标包** | 攻方全队唯一拥有的待安装装置，占用独立槽位，可丢弃、掉落，仅攻方可拾取 | 赛制与回合 | 安装前称「目标包」，安装到点位后进入「已安装装置」倒计时状态。 |
| **购买阶段** | 回合开始的战前整备时间（首测 15 秒），双方隔离在各自出生区，可买装备和调整策略 | 赛制与回合 / 经济 | 仅此阶段允许花钱购买、撤销或更换配置。 |
| **争夺阶段** | 购买结束后正式接敌的阶段（首测 95 秒），直到目标包安装完成、某方全灭或超时结束 | 赛制与回合 | 若超时仍未完成安装（含正在读条），直接判守方胜。 |
| **已安装阶段** | 攻方成功装包后进入的新阶段（首测 35 秒），原争夺时钟作废，守方须在归零前拆除 | 赛制与回合 | 安装瞬间全员获得所在点位公告与统一倒计时。 |
| **半场换边** | 打完前 12 局后两队互换攻守职责的流程 | 赛制与回合 | 保留双方积分，重置所有席位的金钱、连败计数与身上装备。 |
| **决胜局** | 比分战至 12∶12 时触发的第 25 局 | 赛制与回合 | 重新抽签攻守，双方每人统一重置为 4,000 信用点与本方初始手枪。 |

## 三、战斗与枪械

| 术语名 | 通俗定义 | 所属模块 | 备注与易混区分 |
| :--- | :--- | :--- | :--- |
| **TTK（击倒时间）** | 从第一发子弹命中目标开始计算，直到目标生命值归零倒下的理论耗时 | 枪械与交火 | 策划表中的「理论 TTK」排除瞄准、反应和漏枪，仅作数值锚点。 |
| **瞬时射线（Hitscan）** | 开火瞬间沿弹道直接判定是否命中第一个身体或硬遮挡的机制，子弹无飞行时间 | 枪械与交火 | 烟幕不阻挡射线；友方身体挡射线但无伤害。 |
| **急停与精准速度阈值** | 当水平移速降到当前持枪最大跑速的 34% 以下时，角色瞬间进入停稳高精度状态；反方向轻点移动键可迅速完成急停 | 枪械与交火 | 还原 CS2 核心急停手感，而不是单纯等固定读秒恢复。 |
| **停稳固定弹道与移动随机扩散** | 停稳状态下连发走极低随机偏差的简化固定轨迹（易于下拉压枪）；移速超过阈值或腾空时则叠加随机扩散圆 | 枪械与交火 | 既降低复杂压枪背板负担，又严格惩罚跑打。 |
| **护甲与对甲穿透系数** | 花费 600 信用点购买的整局头身防护（无耐久条）；有甲时头/胸/腹伤害乘以各枪专属的对甲穿透系数，腿部不受减伤 | 枪械与交火 / 经济 | 对标 CS2 穿甲区分，决定如「炽焰-47 一枪头」「折线-44 不一枪头」等核心阈值。 |

## 四、经济与购买

| 术语名 | 通俗定义 | 所属模块 | 备注与易混区分 |
| :--- | :--- | :--- | :--- |
| **信用点** | 单场比赛内用于购买枪械、护甲和道具的战斗货币，每位玩家独立持有一个钱包 | 经济与购买 | 仅在本场比赛内有效，与局外衣柜档案完全无关。 |
| **连败档** | 队伍连续输掉回合时逐步提高的败局保底收入档位（首败 +1,900，两连败及以上固定 +2,400） | 经济与购买 | 获胜或半场换边时清零重置。 |
| **继承物** | 上一局结束时仍存活的玩家身上保留带入本局的主武器、护甲或未使用的道具 | 经济与购买 | 不可折现出售；若在购买阶段替换旧主武器，旧物暂存至开战，撤销可找回。 |

## 五、道具与信息

| 术语名 | 通俗定义 | 所属模块 | 备注与易混区分 |
| :--- | :--- | :--- | :--- |
| **通用道具槽** | 每个席位唯一的投掷物栏位，每局最多携带 1 件，从烟幕、闪光、回声片中任选 | 道具与信息 | 局内投出即消耗，当局用完后不可再补买。 |
| **回声片** | 投出后在落点连续播放三声逼真假跑步声、最后附带极短电子尾音的诱饵道具 | 道具与信息 | 前三声与真脚步走同一套声音传播规则，电子尾音用于对手辨别真伪。 |
| **有效目击** | 在视野角度内、未受硬遮挡/烟幕/致盲阻断，直接观测到敌人基准判定部位的事件 | 道具与信息 / Bot | 衣饰边缘、纯脚步声、玩家自由视角均不算有效目击。 |
| **隔墙衰减** | 声音每穿透一处封闭隔墙，其可闻半径减半；连通门洞和烟幕不造成衰减 | 道具与信息 | 用于统一约束玩家听声与 Bot 听觉的公平范围。 |

## 六、角色、外观与敌我识别

| 术语名 | 通俗定义 | 所属模块 | 备注与易混区分 |
| :--- | :--- | :--- | :--- |
| **基础角色** | 决定全部 10 个席位身高、骨架、动作与受击判定体积的统一人物基准模型 | 角色与外观 | 服装与枪皮均挂载在其之上，不改变任何战斗判定体积。 |
| **阵营面罩规则** | 比赛中攻方统一戴半脸面罩遮住口鼻，守方露出口鼻；换边时自动切换 | 角色与外观 / 赛制 | 主界面的摘戴切换仅影响个人展示，不覆盖比赛强制规则。 |
| **外观回退** | 当某件服装或枪皮 ID 失效、未持有或错配枪型时，仅该槽位自动退回默认外观的保护机制 | 角色与外观 | 保证外观异常时绝不影响正常开赛与数值公平。 |

## 七、Bot 与单场学习

| 术语名 | 通俗定义 | 所属模块 | 备注与易混区分 |
| :--- | :--- | :--- | :--- |
| **公平下限** | 全难度 Bot 都必须遵守的拟人约束（如 ≥240ms 识别延迟、≤240°/s 转向速度、禁止透视） | Bot 与学习 | 不管难度怎么调，Bot 都不能打破这些基础规则。 |
| **协作档** | 决定 Bot 在收到报点或队友准备进点时，愿意放弃原任务去支援/配合的概率档位 | Bot 与学习 | 自动难度调节唯一会改变的参数，分休闲、标准、挑战三档。 |
| **有效交火** | 仅用于自动难度评估的样本：人类玩家亲身参与、双方先后实际互相看见并由一方击倒另一方的对枪 | Bot 与学习 | 偷背身秒杀、被第三方收割或中途脱离均不计入样本。 |
| **单场学习** | 仅「挑战」难度开启的记忆机制：基于本场开局前 20 秒的合法目击/报点，统计对手常走区域并在下局提前抽调观察者 | Bot 与学习 | 只记“常从哪来”，不记个人枪法；换边后按新职责分开统计，散场即清空。 |
