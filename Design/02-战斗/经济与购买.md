# 经济与购买

[返回策划总览](../README.md) · [枪械与交火](枪械与交火.md) · [道具与信息](道具与信息.md)

> **模块定位与设计目的**：本模块规定单场比赛内的信用点收支、分阵营商店购买操作与跨局装备继承规则。
> * **为什么采用个人钱包 + 分阵营同定位武器微差**：双方共用统一的防具、道具价格与基础手枪机制，同时保留攻守武器价格差异（如攻方「炽焰-47」2,700 略便宜于守方「守望-41S / 折线-44」2,900–3,000，攻方更易组织起枪进攻，守方买重狙或长枪需更谨慎理财）。
> * **为什么设计连败保底 + 装包奖励**：防止手枪局输掉后连续多局陷入纯手枪挨打。即便手枪局落败，只要成功安装目标包或存钱一局，次局起轻装冲锋枪、第三局起主力步枪的节奏依然清晰稳定。

## 一、信用点收支规则（首测）

* 战斗信用点仅在当前这场比赛内有效，不会带出到局外，与衣柜档案完全隔离。
* **全队同额发放**：单局结束后，**队内存活与阵亡成员领取完全相同的队伍收入**。击杀、助攻、安装/拆除仅记入个人表现统计，不额外发钱。

| 收入 / 规则项 | 金额（信用点） | 触发条件与细节说明 |
| :--- | ---: | :--- |
| **上、下半场起始** | **900** | 各半场第 1 局购买前发放，同时每人自带本方免费初始手枪。 |
| **第 25 局决胜局起始** | **4,000** | 触发决胜局时直接重置余额为 4,000（取代上一局结余），清空继承装备（刚好够双方买齐主力步枪 + 护甲 + 任意道具）。 |
| **胜局奖励** | **+2,700** | 发给获胜方每名成员，并**清零**本队的连败计数。 |
| **第 1 次败局** | **+1,900** | 本队上一局刚赢过，或处于半场第 1 局落败时发放。 |
| **连续第 2 次及以上败局** | **+2,400** | 达到此保底档位后保持固定，直到获胜或半场换边清零。 |
| **攻方装成后仍输局** | **+300** | 攻方完成安装但最终被守方拆除时，额外发给每名攻方，每局最多触发一次。 |
| **个人钱包上限** | **10,000** | 结算时先合并各项奖励，再截断至 10,000；若发生溢出，在收支账单中注明（保证能稳妥攒出重型狙击全套配装）。 |

> 每次半场换边或进入决胜局重置金额时，系统会给出「新阶段预算」提示，防止玩家误以为上一局结余被系统漏发或吞掉。

## 二、商店商品与跨局继承

每名玩家有 4 个固定装备槽位：**副武器（手枪，1 槽）、主武器（1 槽）、护甲（1 槽）、投掷道具（1 槽）**。购买阶段**仅可购买本方阵营专属武器及双方通用武器**；但局中战利品掉落后，**任何阵营均可从地面拾取对方的专属枪械**。

| 槽位 | 商品名称与价格 | 跨局继承与局内流转规则 |
| :--- | :--- | :--- |
| **副武器（1 槽）** | **免费初始**：白隼-12S（守）/ 街头-20（攻）<br/>**进阶手枪**：裁决-57（守 500）/ 疾走-9（攻 500）/ 重响-50（通用 700） | 每局保底拥有本方初始手枪，不可丢弃换钱；购买或拾取进阶手枪后替换副武器，存活带入下局并补满备弹，阵亡则掉落且下局重新领回免费初始手枪。 |
| **主武器（1 槽）** | **冲锋枪**：火花-10（攻 1,050）/ 蜂鸟-9（守 1,250）<br/>**步枪**：炽焰-47（攻 2,700）/ 守望-41S（守 2,900）/ 折线-44（守 3,000）<br/>**狙击枪**：轻羽-08（通用 1,700）/ 长镜-96（通用 4,750） | 回合结束时存活则带走手上那一把，下局自动补满备弹（**即使捡来的对方专属枪也可带入下局**）；阵亡则掉落地面，局内双方均可拾取。 |
| **护甲（1 槽）** | **整套护甲**（双方通用 600） | 整局提供头与躯干防护（无耐久条）；存活带入下局，阵亡则消失。 |
| **投掷道具（1 槽）** | **回声片**（200）/ **闪光**（250）/ **烟幕**（300） | 若当局未投出且存活，保留到下一局；一旦在局中投出即消耗，**当局内无法重新补购**。 |

### 购买与拾取操作规则

* **仅购买阶段可改装**：只能在 15 秒购买阶段花钱买、改选或清空购物篮；开战后立即锁定订单、扣除费用并销毁被替换的旧物。
* **撤销与继承物保护**：
  * 本阶段刚花钱买的新物品，撤销时按**原价全额退款**。
  * 如果你身上带着上一局存活下来的「继承物」（如上一局捡来的「炽焰-47」），在购买阶段换买新主武器时，系统会提示「将放下旧装备」并**将旧物暂存到购买结束前**；若在开战前点撤销，旧物会原样恢复到你身上。
  * **继承物不可卖钱折现**；若点击某件商品时余额不足，保持当前有效配置不变并提示差额。
* **局中地面拾枪**：任何人在局内都可以捡起地上的主武器或进阶手枪。若对应槽位已有武器，须按交互键确认互换；**被捡走的枪械会保留其剩余弹量与原持有者的涂装**。
* **首版限制**：首测版关闭队友间金钱转账与购买期直接发枪功能，每人专注打理自己的钱包。

## 三、三个典型购买决定（手算账单校验）

下面的纸面算式说明了这套经济曲线是如何运作的：

| 典型情景 | 收支算账过程 | 下局实际能买到什么 |
| :--- | :--- | :--- |
| **1. 手枪局全花，未装包就输且阵亡** | 起始 900 − 护甲 600 − 烟幕 300 + 首败 1,900 = **1,900** | **攻方**可起「火花-10 + 护甲 + 闪光 = 1,900」满配冲锋；**守方**可花 1,850 买「蜂鸟-9 + 护甲」，余 50 留空道具。 |
| **2. 同一起点，装成包后被拆且阵亡** | 余 0 + 首败 1,900 + 装包补贴 300 = **2,200** | 多出来的 300 让攻方可以转起「**轻羽-08 + 回声片 = 1,900**」赌远距爆头，或配「火花-10 + 护甲 + 烟幕 = 1,950」并存下 250。 |
| **3. 首败后选择全存钱，再次落败** | 首败 1,900（不花）+ 二连败 2,400 = **4,300** | 哪怕从空身起步，第三局也能买齐主力全套：**攻方**「炽焰-47 + 护甲 + 烟幕 = 3,600（余 700）」；**守方**「折线-44 + 护甲 + 烟幕 = 3,900（余 400）」。 |

## 四、快捷配装逻辑与 Bot 购买原则

* **携带继承物时的计算**：若存活带入了护甲或主武器，购买系统只计算**缺件补齐**的成本。
* **三套快捷推荐规则**（逻辑优先级，手动单买始终可用）：
  1. **保留预算**：保留现有继承物，不花钱购买新装备（用于存钱局）。
  2. **轻装配装**：优先复用继承物，缺件按 **本方冲锋枪（攻 火花-10 / 守 蜂鸟-9）→ 护甲（600）→ 回声片（200）** 的顺序补齐，遇到买不起的那一项即停止。
  3. **步枪配套**：优先复用继承物，缺件按 **本方主力步枪（攻 炽焰-47 / 守 折线-44）→ 护甲（600）→ 烟幕（300）** 的顺序补齐，遇到买不起的那一项即停止。
* **Bot 的购买原则**：
  * 友方与敌方 Bot 使用与玩家完全相同的钱包和分阵营商店价格。
  * 购买前 Bot 会先看一眼队友已经承诺购买的配置以及本队整体预算：如果队伍里缺烟幕，优先让一名道具槽还空着且买得起的队友买烟；全队缺钱时可以集体存钱（或仅买 500 进阶手枪试探）；个别实在缺钱的席位也会老实拿初始手枪打完这一局。
  * **开发验收要点**：重点核对购买前后的余额变化、实际发放到手的装备与下一局的继承状态，杜绝重复退款或靠捡枪卡出折现漏洞。
